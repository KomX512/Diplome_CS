# Дипломный проект "Облачное хранилище"

## Общее описание
Дипломный проект — REST-сервис для авторизованной работы с файлами.\

Сервис позволяет пользователю:

- авторизоваться 
- загружать файлы,
- скачивать файлы,
- удалять файлы,
- переименовывать файлы,
- получать список своих файлов.

Сервис реализцует все методы указанные в [Спецификации](https://github.com/KomX512/Diplome_CS/blob/main/CloudServiceSpecification.yaml)

| Метод  | Путь                      | Описание                      |
| ------ |---------------------------| ----------------------------- |
| POST   | /cloud/login              | Авторизация, получение токена |
| POST   | /cloud/logout             | Загрузка файла                |
| POST   | /cloud/upload/{filename}  | Загрузка файла                |
| GET    | /cloud/download/{filename}| Скачивание файла              |
| PUT    | /cloud/file               | Переименование файла          |
| DELETE | /cloud/file/{filename}    | Удаление файла                |
| GET    | /cloud/list               | Список файлов пользователя    |

Все запросы кроме login должны содержать заголовок `auth-token`.
auth-token - возвращается при запросе login если пользователь есть в базе 

## Ключевые компоненты
Проект является JAVA приложением созданным с использованием Spring Boot, PostgreSQL, JPA.
Добавлены Dockerfile и docker-compose.yml для сборки образа и развёртывания контейнерах
Для запуска без контейнера необходимо создать базу данных cloudstorage.

## Общее описание работы

База данных содержит 3 таблицы.

1. app_users
содержит пользователей и пароли от хранилища

2. auth_tokens
содержит выданные токены

3. files
сюда записываются фалы с указанием на владельца.

При успшной авторизации создается уникальный токен и записывается в таблицу auth_tokens. При  дальнейших обрпащениях проверяется его наличие в этой таблице. В слечае отсутствия запрос не обрабатывается. При logout токен стриается. Дальнейшая работа не возможна без повтроной авторизации login.
Поиск и вывод списк файлов учитывает владельца файла.
